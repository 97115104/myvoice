Running My Voice Locally

Run the voice cloning server locally on your own machine. No API key needed, no data leaves your computer.

Requirements: Python 3.9-3.11, ~4GB disk space for the model, and optionally a CUDA GPU for faster generation.

1. Install dependencies

brew install ffmpeg python@3.11
pip3 install TTS flask flask-cors pydub beautifulsoup4 requests

2. Clone the repository

git clone https://github.com/97115104/myvoice.git
cd myvoice

3. Start the server

python3 server.py

First run downloads the XTTS model (~1.8GB). Server starts on http://localhost:5123

Open the UI at http://localhost:5123/ui

About My Voice

My Voice is a free voice cloning and text-to-speech tool. Clone any voice from a short audio sample and generate natural-sounding speech.

How it works

  1. Start the local server - Run python server.py to start the TTS server on your machine.
  2. Provide a voice sample - Upload an audio file (MP3, M4A, WAV) or record in your browser. 10-30 seconds of clear speech works best.
  3. Enter your text - Type or paste text, or fetch content from a URL.
  4. Generate - Click generate and wait ~10-30 seconds for the AI to synthesize your audio.
  5. Download - Download the audio file or share a link.

Tips for best results

  • Use clear audio with minimal background noise
  • 10-30 seconds of continuous speech is ideal
  • WAV format tends to produce best quality
  • Matching the voice sample language to output language gives best results
  • GPU acceleration significantly speeds up generation

Privacy

When running locally, all voice samples and generated audio stay on your machine — no data leaves your computer.

Host Your Own Backend

Run your own My Voice backend on Hugging Face Spaces with free GPU inference. Follow these steps:

1. Create a Hugging Face Space

  1. Go to huggingface.co/new-space
  2. Name your space (e.g., myvoice)
  3. Select Gradio as the SDK
  4. Select T4 small (free tier) for hardware
  5. Click Create Space

2. Add app.py

Create a file named app.py and paste this code:

import os
os.environ["COQUI_TOS_AGREED"] = "1"

import torch
import torchaudio
import tempfile
import gradio as gr
from TTS.tts.configs.xtts_config import XttsConfig
from TTS.tts.models.xtts import Xtts
from TTS.utils.manage import ModelManager
from TTS.utils.generic_utils import get_user_data_dir

# Download and load model
model_name = "tts_models/multilingual/multi-dataset/xtts_v2"
ModelManager().download_model(model_name)
model_path = os.path.join(get_user_data_dir("tts"), model_name.replace("/", "--"))

config = XttsConfig()
config.load_json(os.path.join(model_path, "config.json"))

model = Xtts.init_from_config(config)
model.load_checkpoint(config, checkpoint_path=os.path.join(model_path, "model.pth"),
    vocab_path=os.path.join(model_path, "vocab.json"), eval=True, use_deepspeed=False)
model = model.to("cuda" if torch.cuda.is_available() else "cpu")

LANGUAGES = ["en", "es", "fr", "de", "it", "pt", "pl", "tr", "ru", "nl", "cs", "ar", "zh-cn", "ja", "ko"]

def generate(text, speaker_audio, language, speed):
    if not text or not speaker_audio:
        return None
    gpt_cond_latent, speaker_embedding = model.get_conditioning_latents(audio_path=speaker_audio)
    out = model.inference(text=text, language=language, gpt_cond_latent=gpt_cond_latent,
        speaker_embedding=speaker_embedding, speed=speed)
    output_path = tempfile.NamedTemporaryFile(suffix=".wav", delete=False).name
    torchaudio.save(output_path, torch.tensor(out["wav"]).unsqueeze(0), 24000)
    return output_path

with gr.Blocks() as demo:
    gr.Markdown("# My Voice - Voice Cloning TTS")
    with gr.Row():
        with gr.Column():
            audio_in = gr.Audio(label="Voice Sample", type="filepath")
            text_in = gr.Textbox(label="Text", lines=3)
            lang = gr.Dropdown(label="Language", choices=LANGUAGES, value="en")
            spd = gr.Slider(label="Speed", minimum=0.5, maximum=2.0, value=1.0, step=0.1)
            btn = gr.Button("Generate", variant="primary")
        with gr.Column():
            audio_out = gr.Audio(label="Output")
    btn.click(generate, inputs=[text_in, audio_in, lang, spd], outputs=audio_out)

demo.queue()
demo.launch()
