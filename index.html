About My Voice

My Voice is a free voice cloning and text-to-speech tool. Clone any voice from a short audio sample and generate natural-sounding speech.

How it works

  1. Provide a voice sample - Upload an audio file (MP3, M4A, WAV) or record in your browser. 10-30 seconds of clear speech works best.
  2. Enter your text - Type or paste text, or fetch content from a URL.
  3. Generate - Click generate and wait ~10-30 seconds for the AI to synthesize your audio.
  4. Download - Download the audio file or share a link.

Tips for best results

  • Use clear audio with minimal background noise
  • 10-30 seconds of continuous speech is ideal
  • WAV format tends to produce best quality
  • Matching the voice sample language to output language gives best results

Privacy

Voice samples are processed on Hugging Face Spaces and deleted after generation. No data is stored permanently.

Host Your Own Backend

Run your own My Voice backend on Hugging Face Spaces with free GPU inference. Follow these steps:

1. Create a Hugging Face Space

  1. Go to huggingface.co/new-space
  2. Name your space (e.g., myvoice)
  3. Select Gradio as the SDK
  4. Select T4 small (free tier) for hardware
  5. Click Create Space

2. Add app.py

Create a file named app.py and paste this code:

import gradio as gr
import torch
from TTS.api import TTS
import tempfile
import os
import base64
import io
from pydub import AudioSegment

# Initialize TTS with XTTS v2
device = "cuda" if torch.cuda.is_available() else "cpu"
tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to(device)

def convert_to_wav(audio_path):
    """Convert any audio format to WAV"""
    audio = AudioSegment.from_file(audio_path)
    wav_path = tempfile.mktemp(suffix=".wav")
    audio.export(wav_path, format="wav")
    return wav_path

def generate_speech(text, speaker_audio, language="en", speed=1.0):
    """Generate speech using voice cloning"""
    if not text or not speaker_audio:
        return None
    
    try:
        # Convert to WAV if needed
        wav_path = convert_to_wav(speaker_audio)
        
        # Generate output
        output_path = tempfile.mktemp(suffix=".wav")
        tts.tts_to_file(
            text=text,
            speaker_wav=wav_path,
            language=language,
            file_path=output_path,
            speed=speed
        )
        
        # Clean up temp WAV
        if wav_path != speaker_audio:
            os.remove(wav_path)
        
        return output_path
    except Exception as e:
        print(f"Error: {e}")
        return None

def generate_speech_base64(text, speaker_audio, language="en", speed=1.0):
    """Generate speech and return as base64 for API use"""
    output_path = generate_speech(text, speaker_audio, language, speed)
    if output_path and os.path.exists(output_path):
        with open(output_path, "rb") as f:
            audio_base64 = base64.b64encode(f.read()).decode()
        os.remove(output_path)
        return {"audio": audio_base64, "format": "wav"}
    return {"error": "Generation failed"}

# Create Gradio interface
with gr.Blocks(title="My Voice TTS") as demo:
    gr.Markdown("# My Voice - Voice Cloning TTS")
    gr.Markdown("Upload a voice sample and enter text to generate speech.")
    
    with gr.Row():
        with gr.Column():
            speaker_audio = gr.Audio(
                label="Voice Sample (10-30s recommended)", 
                type="filepath"
            )
            text_input = gr.Textbox(
                label="Text to speak", 
                placeholder="Enter text...",
                lines=5
            )
            with gr.Row():
                language = gr.Dropdown(
                    choices=["en", "es", "fr", "de", "it", "pt", "pl", 
                             "tr", "ru", "nl", "cs", "ar", "zh-cn", "ja", "ko"],
                    value="en",
                    label="Language"
                )
                speed = gr.Slider(0.5, 2.0, 1.0, step=0.1, label="Speed")
            generate_btn = gr.Button("Generate Speech", variant="primary")
        
        with gr.Column():
            output_audio = gr.Audio(label="Generated Speech", type="filepath")
    
    generate_btn.click(
        generate_speech,
        inputs=[text_input, speaker_audio, language, speed],
        outputs=output_audio
    )

demo.launch()

Once your Space is running, update the server URL in settings to:

https://YOUR-USERNAME-myvoice.hf.space

  • Space sleeps after inactivity - first request wakes it
